# Code of Conduct

## Our standards

We want hint-errors to be a useful and welcoming project for developers of
all experience levels. Participants are expected to:

- be respectful and constructive;
- assume good faith while discussing technical disagreements;
- provide specific, actionable feedback;
- protect other people's privacy; and
- give credit for ideas, code, and other contributions.

## Unacceptable behavior

The following is not acceptable in project spaces:

- harassment, threats, discrimination, or personal attacks;
- publishing private or identifying information without permission;
- sexualized or otherwise unwelcome attention;
- deliberate disruption, trolling, or repeated bad-faith conduct;
- impersonation or deceptive claims about the project; and
- sharing malicious code, phishing links, or credentials.

## Enforcement

Project maintainers may remove, edit, or reject contributions that violate
this code and may temporarily or permanently restrict participation. They
will aim to respond fairly and proportionately to the circumstances.

Report harassment or other conduct concerns privately to a maintainer through
their GitHub profile. Do not create a public issue containing sensitive
details.

This code is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
